# 💎 Molten Rose Dashboard

A responsive, interactive admin dashboard themed in **luxury molten rose gold**
and cinematic pink fluid gradients. Built with React, Tailwind CSS, and Recharts.

## Features
- 📊 Stat cards with KPI deltas
- 📈 Rose-gold gradient revenue sparkline (Recharts)
- 🔍 Live search across order ID / customer / product
- 🏷️ Filter chips for region & status
- ↕️ Sortable table columns
- 🟢 Real-time status pills with pulsing indicators (auto-refresh every 4s)
- 📱 Fully responsive: mobile → desktop

## Usage
- Type in the search bar to filter orders in real time.
- Click filter chips to narrow by region or status.
- Click any table header to sort by that column.
- Toggle the **Live Feed** button to pause/resume live status updates.
